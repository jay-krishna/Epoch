# Epoch

A clean, distraction-free countdown timer for workouts, focus sessions, cooking, and other timed activities. Runs in the browser, installs like a native app, works offline, and supports voice control so the screen can remain untouched during a set.

## Getting started

Open the app in a browser to get started. Tap the central **hh : mm : ss** display to enter a time, then press **Start**.

- **Start** begins the countdown. While running, **Pause** and **Stop** appear.
- **Pause** freezes the time; the button becomes **Resume**.
- **Stop** resets the timer to 00:00:00.
- A soft chime plays when time is up, and five gentle ticks play during the final five seconds.

The Start button remains greyed out until a time above zero is entered.

## Install it as an app

Epoch can be added to the device so it opens full-screen from the home screen or dock, without browser chrome.

- **iPhone / iPad (Safari):** use the Share button, then **Add to Home Screen**.
- **Android (Chrome):** open the menu (⋮), then choose **Install app** or **Add to Home screen**.
- **Windows / macOS (Chrome or Edge):** click the install icon in the address bar, or open the browser menu and choose **Install Epoch**.

Once installed, Epoch launches in its own window and continues to work without an internet connection.

## Voice control

The microphone button enables hands-free control. The browser will request microphone permission the first time; granting it enables voice commands. Begin each command with the wake word **"Epoch"** (or **"hello"**) and speak naturally:

- **"Epoch set 2 minutes 10 seconds"** — sets the time
- **"Epoch start"** — starts the timer
- **"Epoch start 50 seconds"** — sets *and* starts in one step
- **"Epoch pause"** — pauses
- **"Epoch stop"** — resets

Epoch understands hours, minutes, and seconds, and accepts singular or plural forms ("minute" vs "minutes"). Once enabled, the microphone stays listening throughout a session so commands can be issued between sets.

A note on voice: this feature uses the browser's built-in speech recognition, which currently works best in **Google Chrome** (desktop and Android). Some browsers do not support it. If voice seems unresponsive, open the **voice log** (the lines button) to inspect what the microphone is hearing.

## Keep the screen awake

The cup button prevents the screen from dimming or locking while a timer is running — useful for keeping the countdown visible across the room. Tap again to disable this behavior.

## Dark & light

Use the **sun / moon** button to switch themes. Epoch remembers the choice and, on first visit, follows the device's system setting automatically.

## Privacy

Epoch runs entirely in the browser. Microphone access is used only when voice control is enabled, and audio is processed by the browser's speech recognition. There are no accounts, no tracking, and timer settings never leave the device.
